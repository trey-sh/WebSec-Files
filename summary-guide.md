### 1.3. Programação

**Livro recomendado:** Eloquent JavaScript

Se o seu foco é Web Hacking, JavaScript é uma linguagem essencial para estudar.

Comece entendendo variáveis, funções, estruturas condicionais, loops, objetos, arrays, manipulação do DOM e operações assíncronas.

Além disso, procure compreender:

- **HTML:** estrutura das páginas web.
- **CSS:** apresentação e estilos. Não precisa se aprofundar tanto no início.
- **JavaScript:** lógica executada no navegador e interação com aplicações web.
- **SQL:** consultas e interação com bancos de dados.
- **HTTP:** requisições, respostas, métodos, cabeçalhos, cookies, sessões e códigos de status.

Você não precisa se tornar um desenvolvedor experiente antes de estudar segurança web. O importante é entender o suficiente para reconhecer como as aplicações funcionam, identificar comportamentos inesperados e compreender por que determinadas vulnerabilidades acontecem.

## Plataformas para estudar hacking

Depois de construir uma base inicial, comece a estudar vulnerabilidades e praticar em ambientes preparados para isso.

### Plataformas gratuitas

**PortSwigger Web Security Academy:** <https://portswigger.net/web-security>
Nossa principal recomendação para Web Hacking. Possui conteúdo teórico e laboratórios práticos sobre diversas classes de vulnerabilidades, incluindo SQL Injection, XSS, SSRF, controle de acesso, autenticação e muitas outras.

**TryHackMe:** <https://tryhackme.com/>
Possui conteúdos gratuitos e pagos, com trilhas guiadas que ajudam a desenvolver os fundamentos e avançar gradualmente.

### Plataformas com conteúdos pagos

- **Hack The Box (HTB):** <https://www.hackthebox.com/>
- **TryHackMe:** <https://tryhackme.com/>
- **Hacking Club:** <https://app.hackingclub.com/>

> **Observação:** os recursos gratuitos, os planos e a disponibilidade dos laboratórios podem mudar com o tempo.

## Como estudar de verdade

Não basta consumir conteúdo passivamente. Para evoluir em cibersegurança, você precisa combinar teoria, prática, pesquisa e revisão.
